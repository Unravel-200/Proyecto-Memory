# Proyecto Memoria

Juego de terror psicológico y sobrenatural desarrollado en Unreal Engine (C++ + Blueprints).

## Género
Terror psicológico, terror sobrenatural, exploración narrativa, misterio, supervivencia sin combate como sistema principal.

## Ambientación
Campus universitario costarricense ficticio.

## Estructura del repositorio

- `UnrealProject/` — Proyecto de Unreal Engine.
- `Backups/` — Copias de seguridad locales.

La documentación de diseño, arquitectura, checklists y guías de producción
vive únicamente en el repositorio hermano `Proyecto-Memoria-docs`, no en este.

## Control de versiones

Este repositorio usa Git LFS para archivos binarios grandes (`.uasset`, `.umap`, `.fbx`, `.blend`, texturas, audio, ejecutables). Antes de clonar o hacer pull, asegúrate de tener instalado Git LFS:

```
git lfs install
```
